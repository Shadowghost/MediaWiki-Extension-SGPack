# Parser tests for the parser functions and tags SGPack registers.
#
# MediaWiki auto-discovers this file: ParserTestRunner::getParserTestFiles()
# scans <extension>/tests/parser/ for every registered extension. There is no
# extension.json key for it — "ParserTestFiles" is not part of the
# extension.schema.v2 schema and adding it would fail schema validation.
#
# Each case pads the result with x…y so the expected paragraph is unambiguous;
# a parser function returning an empty string on a line of its own produces no
# paragraph at all.
#
# html/php rather than html: these are legacy tag and function hooks, so only
# the legacy parser is expected to render them.

!! test
#in: all elements present in set
!! wikitext
x{{#in:a,b|a,b,c}}y
!! html/php
<p>xa,by
</p>
!! end

!! test
#in: an element missing from the set yields nothing
!! wikitext
x{{#in:a,z|a,b,c}}y
!! html/php
<p>xy
</p>
!! end

!! test
#in: single-element mode returns the elements that matched

</p>
!! end
